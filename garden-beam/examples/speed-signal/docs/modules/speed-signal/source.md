# 속도 신호 예제 원본 메모

절차를 설명하기 위해 만든 가상 입력이다. 실제 표준이나 이해관계자의 승인이 아니다.

- `SRC-1`: 속도값은 0~2500의 정수이며 단위는 0.1 km/h이다. 양 끝값을 포함한다.
- `SRC-2`: 범위 밖 값을 수신하면 invalid 플래그를 설정한다.
- `SRC-3`: 유효 메시지 뒤 100 ms를 초과하도록 새 유효 메시지가 없으면 invalid 플래그를 설정한다.
- `SRC-4`: invalid 상태 뒤 유효 메시지 세 개를 연속 수신해야 플래그를 해제한다.
- `SRC-5`: 전원을 끌 때 대기 중인 시간 초과와 invalid 플래그가 어떻게 되는지 원본에 없다. [ISSUE-001](01-srs/issues.md#issue-001--전원-종료와-시간-초과)에 기록한 예제 책임자의 결정으로 `REQ-005`가 생긴다.

필수 대상 환경은 로컬 Python 모델이다. ECU·HIL·차량 동작은 여기서 명세하거나 검증하지 않는다.

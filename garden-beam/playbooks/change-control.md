# 기준선 변경관리

구현 중 승인된 SRS, STS, 인터페이스, 테스트 기대값 또는 인수 기준을 바꿔야 할 때 사용합니다.

1. 영향받는 승인 산출물, 인터페이스, 동작, 시험, 후속 작업을 추적합니다.
2. 자동차 [SRS](requirements-to-srs.md)와 [STS](srs-to-sts.md) 플레이북으로 영향을 받는 동작과 시험을 확인하고, 공용 `decision`으로 선택과 근거를 기록합니다.
3. `verification`으로 제안된 변경을 실제 산출물과 대조합니다.
4. 변경 기록을 만들며 무관한 작업은 분리해 보존합니다.
5. 변경 결정과 하위 영향이 기록될 때까지 관련 구현을 멈춥니다.

결과: 변경 기록, 영향 분석, 작업 재개 조건.

# 자동차 개발

`garden-beam`는 자동차 도메인 패키지이며 최상위 [SKILL.md](SKILL.md)가 진입점입니다.

## 사용

자동차 작업에는 `$garden-beam`를 사용합니다. 요청한 결과와 현재 산출물을 확인한 뒤 진입 스킬에서 관련 [플레이북](playbooks/)을 선택합니다. 그 절차에 필요한 레퍼런스만 읽습니다.

## 구성

- `SKILL.md` — 필요한 플레이북을 찾는 진입점
- `playbooks/` — 공용 원칙을 선택하고 적용하는 작업 절차
- `references/` — 자동차 맥락, 검토 체크리스트, 브리프, 예제
- `agents/` — UI 메타데이터와 에이전트 지침
- `docs/` — 패키지 구조와 운영 기록
- `scripts/` — 재현 가능한 패키지 검사
- `examples/` — 원본, SRS, STS, 작업, 커버리지, 검증이 포함된 실행 예제

플레이북은 필요한 공용 원칙, 자동차 출처와 승인된 작업의 제약, 각 단계의 근거와 결정을 정합니다. 작업별 절차는 플레이북에, 보조 맥락은 `references/`에 둡니다.

[모듈 산출물 연결 기준](docs/module-deliverables.md)은 공통 연결과 상태 의미를 설명합니다. [속도 신호 예제](examples/speed-signal/README.md)는 한 가지 전체 배치와 인계를 보여 줍니다.

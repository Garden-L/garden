# 자동차 개발

요청한 결과와 현재 산출물을 확인한다. [playbooks/](playbooks/)에서 알맞은 파일을 찾아 전체 단계를 읽고, 명시된 산출물까지 수행한다. 여러 플레이북이 적용되면 의존 순서를 따르고 각 플레이북이 맡은 작업에만 사용한다. 공용 원칙과 작업별 레퍼런스는 플레이북이 선택한다.

## 전체 원칙

- 모든 동작과 기대 결과를 식별 가능한 출처, 승인된 결정, 관찰된 근거에 연결한다. 가정과 미결사항을 드러낸다.
- 원본 요구사항, SRS, STS, 작업 패키지, 코드 변경, 검증 사이의 추적성을 유지한다. 작업 전에 적용할 산출물의 리비전을 확인한다.
- 승인된 기준선을 경계로 다룬다. 요구사항, 인터페이스, 기대 결과, 수용 기준의 변경은 영향과 결정을 확인한 뒤 관련 작업을 이어간다.
- 작업과 완료 주장을 실제 근거에 맞춘다. 계획된 확인과 수행한 확인, 로컬 결과와 통합·ECU·HIL·차량·릴리스 결과를 구분한다.
- 승인을 추정하거나 안전 수준, 표준 준수, 인터페이스, 한계, 기대 동작을 만들어내지 않는다.

작업 단계와 산출물, 인계 조건은 선택한 플레이북이 정한다. 플레이북이 이름으로 호출한 공용 원칙은 이 파일을 기준으로 `../skills/<name>/SKILL.md`에서 읽는다. 결과와 근거, 남은 한계를 보고한다.

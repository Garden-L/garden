# Requirement

State one obligation per requirement identifier. Connect it to its source and an observable condition for judging it. Keep unresolved behavior explicit rather than inventing a limit or interface.

Use the [SRS format](formats/srs.md) and [example](examples/srs-example.md) only when a document shape is needed. The calling playbook sets domain terms, IDs, and approval rules.

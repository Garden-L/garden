# 스킬 설계

스킬이 맡을 판단 하나를 이름으로 나타낸다. 기존 스킬이 이미 맡고 있는지 확인하고 도메인 절차를 재사용 가능한 원칙과 분리한다. 적용 조건과 지침을 그 판단에 집중한다.

배치와 유지 규칙은 저장소의 [작성 원칙](../../docs/skill-authoring-principles.md)을 따른다.

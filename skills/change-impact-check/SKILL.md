# 변경 영향 확인

코드를 작성하기 전에 변경사항이 현재 아키텍처에서 어디에 속하는지 확인하고, 영향을 받을 수 있는 호출자, 인터페이스, 상태, 테스트, 연관 작업을 추적한다.

변경이 국소적이고 영향받는 작업을 파악했는지 판단한다. 확인한 영향을 변경에 반영한다. 영향이 넓거나 책임 경계가 불명확하거나 재설계가 필요하다면 국소적인 수정을 넘어서는 작업임을 표시한다.

# 검증

기대 결과, 산출물 리비전, 환경, 준비 상태, 입력을 확인한다. 관련 사례를 실행하거나 실제 결과를 조사하고 기대와 관찰을 비교해 결론을 뒷받침하는 근거를 확인한다.

실제로 확인한 조건에 대해서만 통과·실패·판정 불가를 말한다. 대체 환경에서 통과해도 필요한 타깃을 확인하지 못했다면 미검증이다. 사례, 근거 위치, 인계 조건은 호출한 플레이북이 정한다.

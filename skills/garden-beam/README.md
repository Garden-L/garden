# 개발 흐름

`garden-beam`는 요구사항 작성부터 구현·검증까지 지원하는 개발 도구 모음입니다.

## 사용

개발 작업을 요청할 때 `$garden-beam`를 호출합니다. 명세 작성, 기능 개발, 버그 수정 등 지원 범위와 작업 자료는 아래 구성을 참고하세요.

## 구성

- `SKILL.md` — 에이전트가 작업을 수행할 때 참고하는 지침
- `playbooks/` — 명세 작성, 기능 개발, 버그 수정 등 작업별 절차
- `agents/` — UI 메타데이터와 에이전트 지침
- `docs/` — 패키지 구조와 운영 기록
- `scripts/` — 재현 가능한 패키지 검사
- `examples/` — 원본, SRS, STS, 작업, 커버리지, 검증이 포함된 실행 예제

[모듈 산출물 연결 기준](docs/module-deliverables.md)은 공통 연결과 상태 의미를 설명합니다. [속도 신호 예제](examples/speed-signal/README.md)는 한 가지 전체 배치와 인계를 보여 줍니다.

# GARDEN-BEAM

플레이북이 이름으로 호출한 공용 원칙은 이 파일을 기준으로 `../<name>/SKILL.md`로 번들로 제공되며, 내부에서 호출되는 스킬은 해당 경로를 참조한다.

# 반드시 따른다
모든 작업이 진행될 때 아래의 사항은 반드시 적용된다.

* 첫 메시지에서는 사용자의 목표와 그 목표를 달성하는 데 필요한 최소 변경을 다시 짚고 작업을 시작한다. 또한 작업, 과정, 산출물의 대한 목표를 분명이 한다. 만약 하위 에이전트에 작업을 전달한다면 모든 목표의 대한 것을 명확하게 지시한다.


# 플레이북

작업에 맞는 플레이북을 선택하고, `playbooks/<title>.md`에서 전체 단계를 확인합니다. `<title>`은 kebab-case입니다. 실행할 단계를 할 일 목록에 등록한 뒤 진행합니다. 여러 플레이북이 선택될 수 있는 경우 작업 순서를 판단한다. 단, 선택이 모호하거나 부합하는 플레이북이 없으면 미결 사항으로 기록합니다.

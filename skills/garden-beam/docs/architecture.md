# 패키지 구조

```text
garden-beam/SKILL.md
        ↓ 작업 흐름 선택
garden-beam/playbooks/*.md
        ↓ 공용 원칙 및 일반 흐름 조합
skills/*
```

패키지 최상위 스킬은 개발 작업을 분류하고 연결합니다. 명세 산출물, 피처, 버그 수정, 리팩터링, 승인 기준선 변경은 중첩 스킬이 아니라 플레이북입니다. 플레이북은 작은 공용 원칙과 일반 방법을 출처 규칙, 작업 범위, 근거, 승인 게이트와 조합합니다. SRS와 STS 같은 구체적인 명세 작성 방법과 예제는 공용 스킬에 둡니다.

[모듈 산출물 계약](module-deliverables.md)은 대상 프로젝트의 결과물 위치와 연결을 정합니다. 구조 검사는 `scripts/validate-module-delivery.py`가 담당하지만, 의미나 타깃 동작 검토를 대신하지 않습니다.

# 흐름 설계

다음 작업이 의존하기 전에 결과나 결정을 확인해야 하는 지점을 단계 경계로 정한다. 각 경계의 입력, 결과, 결정 책임자, 확인 방법을 식별하고 결과와 출처를 다음 단계에 전달한다.

사실과 결정마다 정본 하나를 유지한다. 산출물 경로, 승인, 세부 수준은 호출한 플레이북이 정한다.

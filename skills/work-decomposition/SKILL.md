# 작업 분할

선행 결정, 독립적인 결과, 공유 가변 상태, 통합 지점을 확인한다. 밀접하게 결합된 작업은 한 책임자에게 둔다. 각 부분의 경계, 책임자, 의존성, 확인 방법이 분명할 때만 나눈다.

인터페이스나 의존성이 달라지면 분할을 다시 판단한다. 작업 기록과 실행 순서는 호출한 플레이북이 정한다.

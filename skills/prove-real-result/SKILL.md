# 실제 결과 입증

실제 산출물이나 실행 동작을 명시된 수용 조건과 대조한다. 관련 출력, 상태, diff 또는 증거를 직접 확인한다. 명령 성공이나 에이전트 요약은 해당 주장을 입증할 때만 충분한 근거다.

무엇을 확인했고 어떤 결과를 관찰했는지, 중요한 미검증 조건은 무엇인지 보고한다. 실제 타깃을 실행할 수 없다면 타깃 결과를 미검증으로 표시하고 대체 환경에서 얻은 근거를 설명한다.

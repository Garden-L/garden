# Bounded Implementation

Use when one approved `WORK-###` must be implemented within its defined scope.

1. Read `../skills/implementation-backlog-traceability/SKILL.md` to understand the work packet and traceability contract.
2. Read `../skills/bounded-implementation-execution/SKILL.md` for the implementation boundary.
3. Read `../../skills/shared/architect/SKILL.md` when the change crosses a module or interface boundary.
4. Read `../../skills/shared/tdd/SKILL.md` when a cheap focused regression path exists.
5. Read `../../skills/shared/git-hygiene/SKILL.md` before inspecting or preparing repository changes.

Output: the bounded implementation, its checks, traceability updates, and a local commit when the leaf skill permits it.

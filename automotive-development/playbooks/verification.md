# Implementation Verification

Use after an implementation work package is complete and needs review against its approved requirements, tests, scope, diff, and evidence.

1. Read `../skills/implementation-verification-review/SKILL.md`.
2. Read `../../skills/shared/verification/SKILL.md` and inspect the real artifact and diff.
3. Read `../../skills/shared/git-hygiene/SKILL.md` before making scope claims.
4. Report gaps as findings; do not rewrite requirements or silently fix implementation.

Output: a proportional verification decision with evidence and any required follow-up.

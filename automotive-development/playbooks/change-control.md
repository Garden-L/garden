# Baseline Change Control

Use when implementation reveals a proposed change to an approved SRS, STS, interface, or acceptance criterion.

1. Read `../skills/baseline-change-control/SKILL.md`.
2. Read `../../skills/shared/verification/SKILL.md` to confirm the proposed change against the actual artifacts.
3. Read `../../skills/shared/git-hygiene/SKILL.md` to keep the change isolated from unrelated work.
4. Pause the affected implementation until the change decision and downstream impact are recorded.

Output: a change-control record, impact analysis, and an explicit resume condition.

# SRS to STS

Use when an automotive SRS or requirements document must become a traceable English STS.

1. Read `../../software-test-documentation/SKILL.md`.
2. Read `../../software-requirements-specification/SKILL.md` when the source is an SRS and its decisions or open items affect test scope.
3. Read `../../../../skills/shared/verification/SKILL.md` before reporting coverage.
4. Keep unsupported test environments, limits, and acceptance criteria explicit rather than guessing.

Output: an STS with traceable test cases and ordered procedures.

# Implementation Readiness Review

Use before production code or automated tests begin when an SRS and/or STS exists.

1. Read `../../implementation-readiness-review/SKILL.md`.
2. Read `../../../../skills/shared/verification/SKILL.md` to inspect the actual source artifacts and evidence.
3. Read `../../../../skills/shared/git-hygiene/SKILL.md` if repository state or existing artifacts are part of the review.
4. Stop at unresolved implementation-changing decisions; do not silently approve them.

Output: a readiness decision, actionable issues, and proposed first TDD slices.

# Implementation Verification

Use after an implementation work package is complete and needs review against its approved requirements, tests, scope, diff, and evidence.

1. Apply `verification` for the shared evidence and review method.
2. Apply `automotive-verification-review` for automotive work-item and delivery criteria.
3. Inspect the real artifact and diff before making scope claims. Report gaps as findings; do not rewrite requirements or silently fix implementation.

Output: a proportional verification decision with evidence and any required follow-up.

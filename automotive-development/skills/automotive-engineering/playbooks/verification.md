# Implementation Verification

Use after an implementation work package is complete and needs review against its approved requirements, tests, scope, diff, and evidence.

1. Read `../../implementation-verification-review/SKILL.md`.
2. Read `../../../../skills/traceability/SKILL.md`, `../../../../skills/verification/SKILL.md`, and `../../../../skills/verification-evidence/SKILL.md`.
3. Read `../../../../skills/git-hygiene/SKILL.md` before making scope claims.
4. Inspect the real artifact and diff. Report gaps as findings; do not rewrite requirements or silently fix implementation.

Output: a proportional verification decision with evidence and any required follow-up.

# Baseline Change Control

Use when implementation reveals a proposed change to an approved SRS, STS, interface, or acceptance criterion.

1. Read `../../baseline-change-control/SKILL.md`.
2. Read `../../../../skills/change-impact/SKILL.md` and identify affected downstream artifacts.
3. Read `../../../../skills/verification/SKILL.md` to confirm the proposed change against the actual artifacts.
4. Read `../../../../skills/git-hygiene/SKILL.md` to keep the change isolated from unrelated work.
5. Pause the affected implementation until the change decision and downstream impact are recorded.

Output: a change-control record, impact analysis, and an explicit resume condition.

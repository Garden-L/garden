# Automotive Development

- For a Markdown SRS based on sentence-level requirements, read and follow [Software Requirements Specification](skills/software-requirements-specification/SKILL.md).
- For creating an English Software Test Specification (STS) from an SRS, read and follow [Software Test Documentation](skills/software-test-documentation/SKILL.md).
- For an SRS and/or STS that must be checked before code or automated tests begin, read and follow [Implementation Readiness Review](skills/implementation-readiness-review/SKILL.md).
- For other automotive workflows, use the applicable sub-skill under this directory when one exists.
